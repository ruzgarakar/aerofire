CANLI VERI KURULUMU (3 dosya, repo kokune kopyalanir)

  .github/workflows/live.yml      <- yeni klasor, GitHub burada "her saat calis" talimatini okur
  scripts/live_update.py          <- NASA'dan veriyi ceker, harmonize.py'yi calistirir
  data/static_cells.json          <- fabrika/sabit isi kareleri (elenir)
  web/live.html                   <- canli sayfa (ana siteye dokunmaz): https://ruzgarakar.github.io/aerofire/web/live.html

Mevcut klasorlerine dokunma (harmonize/, web/, data/processed/).

Sirasi:
1) Dosyalari repoya koy, commit + push.
2) GitHub > Settings > Secrets and variables > Actions > New repository secret
   Name: MAP_KEY   Secret: NASA anahtari (kodun ve mesajin icine YAZMA)
3) GitHub > Settings > Actions > General > Workflow permissions: "Read and write permissions" sec, Save.
4) Actions sekmesi > live-update > Run workflow. Yesil tik = tamam.
5) Repoda web/data/live.json olusur.

Kirmizi carpi olursa hata yazisinin ekran goruntusunu at.

NOT: Her saat NASA'dan son 2 gun cekilir, ustune eklenerek son 7 gunluk gecmis tutulur.
Yeni yangin cikinca bir sonraki saatlik calismada haritaya duser (NASA verisi kendisi ~3 saatte bir guncellenir).
